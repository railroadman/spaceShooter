# План по изменению разрешения на динамическое

## 1. Изменение конфигурации в `src/main.js`

- [ ] Открыть файл `src/main.js`.
- [ ] В конфигурации `Phaser.Game` найти объект `scale`.
- [ ] Изменить значение `mode` с `Phaser.Scale.HEIGHT_CONTROLS_WIDTH` на `Phaser.Scale.FIT`. Этот режим сохранит пропорции игры, вписывая её в размер окна.
- [ ] Удалить или закомментировать строки `width: 450` и `height: 640`, чтобы Phaser мог управлять размером автоматически.

## 2. Адаптация игровой сцены `src/scenes/game-scene.js`

- [ ] Открыть файл `src/scenes/game-scene.js`.
- [ ] **Адаптация фона:**
    - [ ] В методе `create()` найти код, создающий фон.
    - [ ] Изменить его так, чтобы он масштабировался или растягивался под новый размер экрана. Возможно, потребуется привязать его размер к `this.cameras.main.width` и `this.cameras.main.height`.
- [ ] **Адаптация UI (счет, жизни):**
    - [ ] В методе `create()` найти код, создающий элементы интерфейса.
    - [ ] Создать функцию, например `repositionUI()`, которая будет размещать эти элементы в нужных местах (например, по углам экрана).
    - [ ] Вызвать `repositionUI()` в конце `create()`.
    - [ ] Добавить обработчик события изменения размера экрана, который будет вызывать `repositionUI()`:
      ```javascript
      this.scale.on('resize', this.repositionUI, this);
      ```
- [ ] **Адаптация границ мира и спавна врагов:**
    - [ ] Проверить, что границы мира (`this.physics.world.bounds`) корректно обновляются.
    - [ ] Убедиться, что логика появления врагов и их движение не привязаны к фиксированным координатам `450` и `640`, а используют динамические размеры, например `this.cameras.main.width`.

## 3. Тестирование

- [ ] Запустить игру.
- [ ] Изменять размер окна браузера и проверять, что:
    - [ ] Игра корректно масштабируется без искажений.
    - [ ] Фон полностью покрывает видимую область.
    - [ ] Элементы UI (счет, жизни) остаются на своих местах (в углах экрана).
    - [ ] Враги появляются корректно, и игрок не может вылететь за пределы видимой области.
